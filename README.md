# Order Processing Simulator

Учебный проект на JavaScript, имитирующий автоматическую обработку заказов интернет-магазина.

## О проекте

Программа моделирует работу интернет-магазина: принимает список заказов, проверяет наличие товаров на складе, рассчитывает стоимость покупок, скидки и доставку.

## Функциональность

- Обработка нескольких заказов с помощью цикла `for`.
- Проверка статуса заказа и пропуск отменённых заказов.
- Проверка наличия товаров на складе.
- Использование `continue` для пропуска заказов и `break` для остановки обработки.
- Автоматическое уменьшение складских остатков.
- Расчёт стоимости товаров.
- Расчёт скидок в зависимости от уровня покупателя.
- Определение стоимости доставки.
- Расчёт итоговой стоимости заказа.
